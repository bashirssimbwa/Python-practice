===First push in a Fresh Repo===
1. Create a repo in Github
2. git init 
3. git remote add  origin "[remote_repository_URL]" 
4. git add .
5. git commit -m "Commit message"
#Shifting from master branch to main branch
6. git branch -M main 
7. git pull origin  main --allow-unrelated-histories
#Check Updates
8. git status
9. git  add "READMEmd"
#Final Push
10. git push origin main

=====Incase of a bad commit and u want to revert to a good working state==============

Step 1: We track the most recent commits including the bad one

       - git log --oneline -8    i) -8 specifically limits the output to the 8 most recent commits in your repository hsitory
                                - This lists the number of latest commits by numbers(hash)

Step 2: We then revert back to our desired working commit by number
      
      - git reset --hard "hashnumber"   i) This reverts the commit to that working state

step 3: (Optional); Confirm weather  the repo is back to unstaged state(red color )

        git status

step 4: Force push the clean history to github

       - git push origin main --force
